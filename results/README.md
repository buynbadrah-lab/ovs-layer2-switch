# Experimental Results

This directory contains the results of the virtual switch
experiments.

## Metrics

The following metrics are evaluated:

- Connectivity
- Flow packet count
- Flow byte count
- RTT
- Throughput
- Packet loss
- Jitter

## Test Environment

- Ubuntu
- Open vSwitch
- Mininet
- OpenFlow 1.3
- Python
- Wireshark
- iperf

Results will be added after completing the experiments.
