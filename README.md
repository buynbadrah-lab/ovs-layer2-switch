# Open vSwitch Layer 2 Switch

A virtual Layer 2 switch implementation and experimental
network environment based on Open vSwitch, Linux, Mininet,
OpenFlow, Python and Wireshark.

## Project Goals

- Study Open vSwitch architecture
- Implement Layer 2 forwarding
- Implement MAC-based forwarding
- Configure VLANs
- Test STP
- Use OpenFlow flow rules
- Build virtual network topology using Mininet
- Analyze packets using Wireshark
- Evaluate network performance

## Technologies

- Ubuntu
- Open vSwitch
- Mininet
- OpenFlow 1.3
- Python
- Wireshark
- iperf
